# B／C v2.1：Google 行事曆快捷新增版
更新日期：2026-10-21

## 使用方式
1. 新增或編輯任務，填好開始、結束日期及時間；全天任務勾選「全天」。
2. 在任務卡按「加入 Google 行事曆」。
3. Google 會開啟預填標題、起迄時間與內容的行程，由你確認帳號、目標行事曆，再按「儲存」。
4. 提前通知與 Google 行程顏色請在該 Google 行程內設定。

不需要設定 OAuth、用戶端 ID 或 API，也不下載 ICS。若 Google 尚未登入，請直接在 Google 網站登入 Gmail 帳號；APP 不會向你索取密碼。

## 本次改動
- B「玫瑰日序」與 C「社區營運所」都移除授權、讀取同步、訂閱與事件版本操作入口。
- 移除 Google 登入 SDK、Calendar API 程式與定時讀取。
- 任務資料、分類、資料夾、聯繫人、社區、起迄時間、完成統計、標題六色、追蹤內容與 2026／2027 假日保留。
- 提醒數量改為「提醒需求」，會放進 Google 行程內容中供你參考；它不是已套用的通知。
- 任務時間採臺北時間。全天結束日期會轉為 Google 使用的次日，不會少一天。
- 內容過長無法完整放入連結時會提示縮短，不會修改或刪除原任務。

## 這種方式的範圍
- 開啟 Google 行程編輯頁不代表已儲存；APP 無法確認你是否最後按了儲存。
- 不會讀回原有行程、同步別人的日曆、更新或刪除 Google 既有事件。
- 每次加入並儲存都可能建立新行程。修改本機任務後，請在 Google 修改原行程，避免重複。
- APP 標題顏色保存在本機；Google 事件的顏色請在 Google 內選。
- 本機任務不會在網頁關閉後推播提醒；Google 已儲存的行程依 Google 與手機的通知設定處理。
- 主要聯繫人只會以文字放進行程內容，不會自動新增為受邀者。
- 任務資訊只在你點加入時透過該行程連結交給 Google，沒有額外後端服務。
